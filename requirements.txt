# Amazon Author Advertising Agent

A production-ready starter growth engine for Daniel Kwesi Ansah's author brand and sales ecosystem.

This system promotes:
- Amazon Author: https://amazon.com/author/danielkwesiansah
- Selar Store: https://selar.com/m/danielkwesiansah

## Included features

- Landing page and brand funnel for author visibility
- Analytics dashboard and channel performance summary
- Product catalog with Amazon + Selar-focused offers
- AI-assisted ad creative generation
- Admin dashboard with product and campaign management
- Campaign templates for Amazon, Selar, Email, and SMS
- Email and SMS communication hooks with mock or real integrations
- Selar sync support for product imports
- SQLite-backed CMS storage for products and campaigns
- Docker and deployment configuration for production hosting

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open:
- http://localhost:5000/
- http://localhost:5000/dashboard
- http://localhost:5000/admin

Admin login:
- Username: daniel
- Password: author123

## Environment variables

Copy `.env.example` and update it:

```bash
cp .env.example .env
```

Key values:
- SECRET_KEY
- ADMIN_USERNAME
- ADMIN_PASSWORD
- SELAR_API_URL
- SELAR_API_KEY
- OPENAI_API_KEY
- SMTP_HOST / SMTP_PORT / SMTP_USER / SMTP_PASSWORD
- TWILIO_ACCOUNT_SID / TWILIO_AUTH_TOKEN / TWILIO_PHONE_NUMBER

## Deployment

This repo includes Docker and Render configuration for easier cloud deployment.

### Docker

```bash
docker build -t daniel-author-agent .
docker run -p 5000:5000 daniel-author-agent
```

### Render

The included `render.yaml` creates a web service with environment variables attached.
